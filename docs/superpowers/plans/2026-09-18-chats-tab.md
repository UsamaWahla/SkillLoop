# Chats Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Chats inbox tab, start the first conversation from Home, and remove the Sessions Message button, without changing the existing thread screen.

**Architecture:** Pure helpers build inbox rows and pick a match skill id. Home calls `ensureMatchForChat` (same match lookup/insert as `request-session.tsx`) then `router.push('/chat')`. A new `(tabs)/chats` screen loads matches + messages, filters to threads with at least one visible message, and opens the existing `app/chat.tsx` stack screen.

**Tech Stack:** Expo Router tabs, React Native, Supabase (`matches`, `messages`, `message_receipts`, `message_hidden`, `profiles`). Unit tests via `node --experimental-strip-types --test`.

**Spec:** `docs/superpowers/specs/2026-09-18-chats-tab-design.md`

## Global Constraints

- Do not rewrite `app/chat.tsx` thread behavior (text, voice, media, receipts, reactions).
- Inbox is existing conversations only (match must have at least one message the current user can see).
- Empty threads after Home → Chat must not appear on the Chats tab until the first send.
- Tab order: Home, Chats, Sessions, Profile.
- Inbox copy for empty state: `No chats yet. Open someone’s profile on Home and tap Chat to start a conversation.`
- Fallback display name: `Skill partner`.
- Tests live next to helpers as `lib/*.test.ts` and import with `.ts` extensions (existing pattern).
- Do not add new SQL/RPCs in v1.
- Do not add inbox realtime in v1; refresh on tab focus and pull-to-refresh.
- No pagination on the Chats list.

```ts
export function pickMatchedSkillWanted(
  offered: { skill_id: string }[],
  wantedSkillIds: string[]
): string | undefined {
  const wanted = new Set(wantedSkillIds);
  const overlap = offered.find((s) => wanted.has(s.skill_id));
  if (overlap) return overlap.skill_id;
  return offered[0]?.skill_id;
}
```

### Task 2: Inbox row builder (pure)

**Files:**
- Create: `lib/chat-inbox.ts`
- Test: `lib/chat-inbox.test.ts`

**Interfaces:**
- Consumes: `getMessagePreview` from `lib/chat-media.ts` (existing). Tests should not import `chat-media.ts` (it pulls Supabase). Duplicate the preview rule in the builder by importing `getMessagePreview` only if it stays side-effect free besides types — it currently imports supabase. **Do not import `getMessagePreview` from `chat-media.ts` in this helper.** Inline preview using the same rules: if `deleted_for_everyone_at` then `This message was deleted`; if `message_type` is `image`/`video`/`audio`/`document` then `Photo` / `Video` / `Voice message` / `media_name ?? 'Document'`; else `content`.
- Produces:
  - `export type ChatInboxRow = { matchId: string; otherUserId: string; otherName: string; otherAvatarUrl: string | null; lastMessageAt: string; preview: string; unreadCount: number }`
  - `export type InboxMatch = { id: string; user_id_1: string; user_id_2: string }`
  - `export type InboxMessage = { id: string; match_id: string; sender_id: string; content: string; message_type: 'text' | 'image' | 'video' | 'document' | 'audio'; media_name: string | null; created_at: string; deleted_for_everyone_at: string | null; message_receipts: { user_id: string; read_at: string | null }[] }`
  - `export type InboxProfile = { full_name: string | null; avatar_url: string | null }`
  - `export function buildChatInboxRows(input: { currentUserId: string; matches: InboxMatch[]; messages: InboxMessage[]; hiddenIds: Set<string>; profiles: Record<string, InboxProfile> }): ChatInboxRow[]`
  - `export function formatInboxTime(iso: string, nowMs: number): string`

**Rules for `buildChatInboxRows`:**
- For each match, ignore messages in `hiddenIds`.
- If no remaining messages, omit the match.
- Last message = remaining message with latest `created_at`.
- `otherUserId` = the match user that is not `currentUserId`.
- `otherName` = `profiles[otherUserId].full_name` trimmed, or `'Skill partner'`.
- `unreadCount` = remaining messages where `sender_id !== currentUserId` and the receipt for `currentUserId` has null/missing `read_at`.
- Sort rows by `lastMessageAt` descending.

**Rules for `formatInboxTime`:**
- Same local calendar day as `nowMs`: `HH:MM` 2-digit (use `toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })`).
- Else: `toLocaleDateString()` with default locale.

async function handleStartChat(item: UserCard) {
  if (!currentUserId) return;
  try {
    const skillId = pickMatchedSkillWanted(item.offeredSkills, myWantedSkillIds);
    const matchId = await ensureMatchForChat({
      currentUserId,
      otherUserId: item.id,
      compatibilityScore: item.compatibilityScore,

      error instanceof Error ? error.message : 'Unknown error'
    );
  }
}
